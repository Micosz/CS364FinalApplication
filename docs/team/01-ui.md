# คนที่ 1 · หน้าจอเกมและภาษา

## เปิดโปรเจกต์

แตก ZIP แล้วเปิดโฟลเดอร์ CS364FinalApplication ที่มี settings.gradle ใน Android Studio ใช้ Gradle JDK ของ Studio และ SDK Platform 37 รอ Sync เลือก app และ Emulator API 24 ขึ้นไป แล้วกด Run รายละเอียดอยู่ใน README.md ที่รากโปรเจกต์

## ไฟล์ที่รับผิดชอบ

- `app/src/main/java/th/ac/tu/cs364/wordward/GameScreen.java`
- `app/src/main/res/layout/activity_game.xml`
- `app/src/main/res/values/strings.xml`
- `app/src/main/res/values-th/strings.xml`

## งานของคุณ

ปรับหน้าทายคำให้แยกผลล่าสุดกับรายการเรียงอันดับชัดเจน เพิ่มการเน้นแถวคำซ้ำ ปรับตัวอักษรและพื้นที่กดให้เหมาะกับมือถือ เติมข้อความอังกฤษและไทยเป็นคู่เมื่อเพิ่มป้ายใหม่

รับ GameRound มาแสดงผ่าน GameScreen.show และส่งการเดา ขอคำใบ้ หรือสลับภาษาผ่าน callbacks ใน constructor การนับยอดและการบันทึกอยู่กับคน 3 และ 5

## ลองบนฐานและตรวจงานหลังแก้

1. พิมพ์ blue แล้ว pencil ดูว่าคำล่าสุดอยู่ใต้ช่องเดา และ blue ยังอยู่เหนือ pencil ในวันที่คำลับคือ ocean
2. ขอคำใบ้ สลับไทย/English และลองจอเล็ก ตรวจว่าช่องเดา ปุ่ม รายการ และยอดเดิมยังอ่านและกดได้

รัน `./gradlew :app:testDebugUnitTest :app:assembleDebug` หรือใช้ `.\gradlew.bat` แทน `./gradlew` ใน Windows PowerShell ไฟล์ test ใหม่วางใน `app/src/test/java/th/ac/tu/cs364/wordward/`

## ส่งงาน

สร้าง branch จาก Terminal ที่รากโปรเจกต์ก่อนเริ่มแก้

```sh
git switch -c member/01-ui
```

หลังตรวจ diff และ commit ไฟล์ของตนแล้ว ส่ง branch ด้วย

```sh
git push -u origin member/01-ui
```

เปิด PR เข้า main ใส่ชื่อไฟล์ที่แก้ สิ่งที่เปลี่ยน และผลที่ลองจริง คน 5 ช่วยตรวจการทำงานร่วมกันก่อนรวม
