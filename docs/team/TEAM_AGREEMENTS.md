# ข้อตกลงทีม Wordward และหน้าที่สมาชิก

อัปเดตวันที่ 14 พฤศจิกายน 2569

เอกสารนี้สรุปขอบเขตและพฤติกรรมที่กลุ่มยืนยันแล้ว เพื่อให้สมาชิกทั้ง 5 คนพัฒนาและทดสอบได้ตรงกัน โดยเฉพาะคลังคำ 1,000 คำ โจทย์รายวัน 31 วัน และการเริ่มรอบวันนี้ใหม่ ข้อตกลงที่ยืนยันในเอกสารนี้ใช้ปรับรายละเอียดส่วนเดียวกันใน issue #1–#5 ส่วนฟีเจอร์ที่ยังไม่ตกลงให้คงเป็นรายการรอยืนยัน

## 1 ขอบเขตเกมที่ยืนยันแล้ว

| เรื่อง | ข้อตกลง |
|---|---|
| คำที่ใช้เล่น | เดาคำภาษาอังกฤษ ส่วนติดต่อผู้ใช้รองรับไทยและอังกฤษ |
| คลังคำ | คำหลักประมาณ 1,000 คำ ใช้ชุดคำหลักร่วมกันทุกโจทย์ รูปคำหรือ alias ไม่นับซ้ำเป็นคำหลักใหม่ |
| จำนวนโจทย์ | 31 โจทย์ คำลับไม่ซ้ำกันในช่วง 31 วัน และอยู่ในคลังคำหลัก |
| การเปิดโจทย์ | วันละ 1 โจทย์ เปลี่ยนวันตาม Asia/Bangkok ผู้เล่นที่ใช้ข้อมูลรุ่นเดียวกันและวันเริ่มชุดเดียวกันได้โจทย์เดียวกัน |
| การจัดอันดับรุ่นส่ง | ใช้ตารางอันดับออฟไลน์ใน TSV ตามโครงสร้างฐาน แต่ละโจทย์จัดอันดับคำหลักครบชุด คำลับเป็นอันดับ 1 เพียงคำเดียว |
| คำซ้ำและคำนอกคลัง | ไม่เพิ่มจำนวนครั้ง รูปคำที่ชี้คำหลักเดียวกันถือเป็นคำเดียวกัน |
| ภาษาและธีม | รองรับไทย/อังกฤษ และ Day/Night เก็บค่าที่ผู้ใช้เลือกข้ามการเปิดแอป |
| ขอบเขตเพิ่มเติม | โมเดล AI ภายในแอป คลัง 20,000–50,000 คำ และโจทย์ 365 วัน ไม่ใช่เกณฑ์ตรวจรับของรุ่น 1,000 คำ/31 วัน |

### การเตรียมข้อมูลของคน 2

- เพิ่มคำและโจทย์เป็นช่วงย่อยที่ตรวจได้ พร้อมคงข้อมูลตัวอย่างเล็กสำหรับ unit tests แยกจากข้อมูลจริง
- ทุกโจทย์มีคำหลักชุดเดียวกัน ไม่มีคำซ้ำ ไม่มีคำตกหล่น และ alias ทุกตัวชี้ไปยังคำหลักที่มีอยู่
- บันทึกจำนวนคำหลักและ alias จริง แหล่งข้อมูล วิธีเตรียมและตรวจอันดับ รวมถึงส่วนที่ใช้โค้ด สื่อ หรือ AI ภายนอก
- ใช้รหัสรุ่นชุดข้อมูลร่วมกับคน 5 เพื่อไม่ให้เซฟเก่าใช้อันดับผิดเมื่อแก้ข้อมูล
- รายงานอันดับบนของโจทย์ตัวอย่างให้เพื่อนช่วยตรวจความสมเหตุสมผล
- โค้ดเลือกโจทย์ต้องใช้ลำดับคำลับที่คงที่และตรงกับคน 4

### จุดที่ยังต้องตกลงเรื่อง 31 วัน

ขอบเขต 31 โจทย์ใน 31 วันยืนยันแล้ว แต่วันเริ่มชุดโจทย์จริงและพฤติกรรมก่อนเริ่ม/หลังวันที่ 31 ยังไม่ได้ยืนยัน ไม่ถือว่ากลุ่มอนุมัติการวนกลับวันแรกหรือการปิดเกมโดยอัตโนมัติ คน 4 เสนอนโยบายให้ทีมยืนยันและให้คน 5 เชื่อมก่อนทดสอบขอบเขตวันจริง ฐานเดิมใช้ epoch 7 พฤศจิกายน 2026 และวนลำดับโจทย์ จึงต้องทบทวนให้ตรงกับข้อตกลงนี้

## 2 เริ่มรอบวันนี้ใหม่

เพิ่มปุ่ม “เริ่มรอบวันนี้ใหม่” เพื่อให้เล่นโจทย์เดิมซ้ำได้ และมีการยืนยันก่อนลบข้อมูลรอบ

### กติกาที่ต้องได้

1. หลังเริ่มใหม่ยังเป็นโจทย์เดิมของวันนี้ ไม่เปลี่ยนคำลับหรือปลดล็อกโจทย์วันถัดไป
2. ล้างรายการคำที่เดา รายการคำใบ้ จำนวนครั้งทั้งหมด และสถานะชนะของรอบนั้น
3. กลับเป็นรอบที่กำลังเล่น รายการว่าง จำนวนรวม/เดาเอง/คำใบ้เป็นศูนย์ ไม่มีคำล่าสุด และไม่มีอันดับดีที่สุดจากรอบเก่าค้าง
4. เก็บภาษาและธีมที่เลือกไว้ ล้างเฉพาะข้อมูลรอบ
5. ใช้ได้ทั้งระหว่างเล่นและหลังชนะ
6. การกด Back ออกจากแอปยังเก็บรอบไว้เพื่อเล่นต่อ และมีการป้องกันออกโดยไม่ตั้งใจ การออกจากแอปไม่ใช่การเริ่มรอบใหม่
7. แสดงหน้าต่างยืนยันก่อนลบ กดยกเลิกแล้วสถานะต้องเหมือนเดิมทุกอย่าง
8. เมื่อยืนยันแล้วบันทึกรอบว่างลงเครื่องให้สอดคล้องกับหน้าจอ ปิดแล้วเปิดแอปใหม่ต้องไม่คืนรายการที่ลบแล้ว

### ข้อความยืนยัน

ภาษาไทย:

> เริ่มรอบวันนี้ใหม่?
>
> คำที่เดาและคำใบ้ทั้งหมดในรอบนี้จะถูกลบ คุณจะเริ่มใหม่ด้วยโจทย์เดิม
>
> ปุ่ม: ยกเลิก / เริ่มใหม่

ภาษาอังกฤษ:

> Restart today's round?
>
> All guesses and hints in this round will be deleted. You will restart with the same puzzle.
>
> Buttons: Cancel / Restart

### หน้าที่ร่วมกัน

| คน | สิ่งที่รับผิดชอบ |
|---|---|
| 3 | กำหนดการคืนสถานะรอบว่างและเมธอดรีเซ็ต ทดสอบทั้งรอบกำลังเล่นและรอบชนะ พร้อมแจ้งสัญญาให้คน 5 |
| 1 | ทำปุ่ม หน้าต่างยืนยัน ข้อความไทย/อังกฤษ และการแสดงรอบว่าง ส่งการยืนยันผ่าน callback ให้คน 5 |
| 5 | เชื่อมการยืนยันกับกติกาของคน 3 และการบันทึก ล้างเฉพาะข้อมูลรอบ เก็บภาษา/ธีม และตรวจการกู้หลังเริ่มใหม่ |
| 4 | ตรวจการรีเฟรชวันร่วมกับคน 5 โดยเฉพาะกรณีเปิดหน้าต่างยืนยันค้างข้ามเที่ยงคืน ให้เสนอพฤติกรรมกรณีนี้ก่อนลงมือ |
| 2 | คงรหัสโจทย์และข้อมูลอันดับให้การเริ่มใหม่ยังได้คำลับเดิม |

### เกณฑ์ตรวจรับการเริ่มใหม่

- [ ] ระหว่างเล่น กดยกเลิกแล้วคำ อันดับ จำนวนครั้ง คำใบ้ และสถานะเดิมไม่เปลี่ยน
- [ ] ระหว่างเล่น กดยืนยันแล้วรายการและยอดทุกประเภทว่าง/ศูนย์ สถานะกลับมาเล่นได้
- [ ] หลังชนะ กดยกเลิกแล้วยังชนะ กดยืนยันแล้วกลับไปเล่นโจทย์เดิมได้
- [ ] ภาษาและธีมคงเดิมหลังเริ่มใหม่
- [ ] ปิดแล้วเปิดแอปใหม่หลังยืนยัน ไม่ดึงประวัติที่ลบกลับมา
- [ ] เดาคำที่เคยเดาก่อนเริ่มใหม่ได้ และนับเป็นครั้งแรกของรอบใหม่
- [ ] กด Back ยกเลิกการออกได้ และยืนยันออกแล้วกลับเข้าแอปยังเล่นต่อจากรอบเดิม
- [ ] เก็บภาพและผลทดสอบยกเลิก/ยืนยันสำหรับหลักฐาน rubric ข้อ 4.3

## 3 เจ้าของไฟล์และวิธีเชื่อมงาน

| คน | ไฟล์หลัก | ขอบเขต |
|---|---|---|
| 1 | GameScreen.java, layout, strings และ resources ธีม | หน้าจอ ภาษา ธีม สถานะ และหน้าต่างยืนยัน |
| 2 | WordRanker.java, puzzles.tsv, aliases.tsv | คลังคำ รูปคำ อันดับ และข้อมูล 31 โจทย์ |
| 3 | GameRound.java และ unit tests ของกติกา | อนุมัติการเพิ่มคำ การนับครั้ง ชนะ รับคำใบ้ และรีเซ็ตรอบ |
| 4 | HintEngine.java, DailyWordProvider.java และ unit tests | เลือกคำใบ้และกำหนดโจทย์รายวัน |
| 5 | GameStorage.java, GameActivity.java, Manifest และการตั้งค่า build | บันทึก กู้เกม lifecycle Back และเชื่อมทุกส่วน |

- GameRound เป็นแหล่งตัดสินกติกาและยอด คน 4 เลือกคำใบ้ คน 5 เรียกและบันทึก คน 1 แสดงผล
- ก่อนเปลี่ยนชื่อเมธอด พารามิเตอร์ ค่าที่คืน หรือรูปแบบข้อมูล ให้ตกลงกับผู้เรียกใช้ ระบุสัญญาใน issue/PR
- งานรีเซ็ตต้องระบุให้ชัดว่า GameScreen ส่งเหตุการณ์อย่างไร GameRound คืนรอบว่างอย่างไร และ GameStorage บันทึกอย่างไร ชื่อเมธอดจริงให้เจ้าของตกลงกันก่อนใช้
- ให้คน 5 ดูแล GameActivity.java เป็นหลัก สมาชิกแจ้งจุดเชื่อมที่ต้องแก้เพื่อหลีกเลี่ยงแก้ทับกัน
- ค่าภาษาและธีมต้องแยกจากข้อมูลรอบ การรีเซ็ตไม่ล้าง SharedPreferences ทั้งชุด
- ก่อนใช้ข้อมูลครบ 1,000 คำ ให้คน 4 ปรับช่วงคำใบ้ตามขนาดจริง ตัวอย่างช่วง 1,000–5,000 จากสเปกเก่าไม่ใช้ตรง ๆ กับคลังนี้
- งานเริ่มใหม่ที่ยืนยันแล้วแยกจาก Give up และสถิติสะสม ซึ่งยังต้องตกลง ไม่ถือว่ามีการอนุมัติสองฟีเจอร์นั้นเพิ่ม

## 5 หลักฐาน รายงาน และงานส่ง

ทุกคนเขียนคำอธิบายส่วนของตัวเอง พร้อมวิธีทดสอบ ผลที่คาดหวัง ผลจริง ภาพหลักฐาน และปัญหา–วิธีแก้–ผลหลังแก้ รวมทั้งแจ้งแหล่งที่มาหรือ AI ที่ใช้ตามจริง

| คน | งานประกอบที่ประสาน |
|---|---|
| 1 | ภาพไอคอน หน้าหลัก เส้นทางเล่นหลัก ไทย/อังกฤษ Day/Night และอย่างน้อย 2 รูปแบบหน้าจอ |
| 2 | แหล่งข้อมูล โค้ด สื่อ และ AI รวมถึงจำนวนคำ/โจทย์และการสร้างอันดับจริง |
| 3 | รายการฟังก์ชันและตารางผลทดสอบของทุกคน |
| 4 | ประกอบรายงาน Word/PDF ตรวจความครบของ rubric และรวบรวมเลขหน้าหลักฐานสำหรับ Checklist |
| 5 | โฟลเดอร์โปรเจกต์ APK พร้อมติดตั้ง และผลทดสอบรวม |

เส้นทางตรวจรวม: เปิดเกม → เดาคำ → เดาซ้ำ/คำนอกคลัง → ขอคำใบ้ → สลับภาษา/ธีม → ออกและเปิดใหม่ → ชนะ → ยกเลิก/ยืนยันเริ่มรอบใหม่ → ตรวจการเปลี่ยนวันไทย

## 6 สิ่งที่ยังไม่ยืนยัน

- วันเริ่มชุดโจทย์ 31 วันและพฤติกรรมก่อนเริ่ม/หลังวันที่ 31
- กรณีหน้าต่างยืนยันเริ่มใหม่เปิดค้างข้ามเที่ยงคืน
- Give up และสถิติสะสม/streak รวมถึงผลของการเล่นซ้ำหากจะเพิ่มสถิติ
- ชื่อเมธอดและ callback ใหม่สำหรับรีเซ็ต ให้คน 1/3/5 ตกลงก่อนแก้จุดเชื่อม

Issue เดิมอ้าง CONTEXTO_APP_SPEC.md แต่ไม่พบไฟล์ชื่อนี้ใน main ณ วันที่ตรวจ ข้อตกลงล่าสุดเรื่อง 1,000 คำ/31 วันและเริ่มรอบใหม่จึงเขียนครบในไฟล์นี้เพื่อให้ทีมเปิดอ่านได้จาก repo โดยไม่ต้องอาศัยไฟล์สเปกภายนอก
