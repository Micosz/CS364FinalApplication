## วิธีทำงาน

### บันทึก

`save(round, ranks)` แปลงประวัติตามลำดับเวลาเป็นรายการ `[word, rank, isHint]` แล้วตรวจความถูกต้องก่อนเขียนทับเซฟเดิม ยอดและสถานะชนะไม่ถูกเก็บซ้ำ เพราะ GameRound คำนวณคืนจากประวัติได้

ข้อมูลรอบอยู่ในค่า `round` ค่าเดียว:

```json
{
  "schema": 1,
  "day": "2026-11-18",
  "secret": "ocean",
  "ranking": "<SHA-256 ของคำทั้งหมดตามลำดับอันดับ>",
  "entries": []
}
```

ตัวอย่างนี้อธิบายรูปแบบ ไม่ใช่การระบุว่า ocean เป็นคำลับของวันที่ 18 ในข้อมูลจริง

ค่า `language` และ `theme` อยู่คนละ key กับข้อมูลรอบ และไม่มีการเรียก clear() ล้าง preferences ทั้งชุด

### กู้ข้อมูล

`open(day, ranks)` ตรวจ schema และวันที่ก่อนอ่านประวัติ ถ้าเป็นวันอื่นจะคืนรอบว่างของวันที่ร้องขอโดยไม่เอาประวัติวันเดิมมาปะปน

สำหรับวันเดียวกัน ตรวจคำลับและ SHA-256 ของตารางอันดับปัจจุบัน Hash ครอบคลุมทุกคำตามลำดับอันดับ จึงตรวจได้แม้คำที่เคยเดายังมีอันดับเดิมแต่ตำแหน่งคำอื่นเปลี่ยน และไม่ต้องแก้ไฟล์ของคน 2 เพื่อเพิ่ม version ด้วยมือ

ตรวจแต่ละรายการว่า:

- มี 3 ค่าและชนิดข้อมูลตรงตามรูปแบบ
- เป็นคำหลักตัวพิมพ์เล็ก อันดับเป็นจำนวนเต็มบวก และตรงกับคำในอันดับปัจจุบัน
- ไม่มีคำซ้ำ ไม่มีรายการหลังชนะ
- คำใบ้ไม่ใช่อันดับ 1 และต้องดีกว่าอันดับดีที่สุดก่อนหน้า

หากรายการท้ายเสีย จะไม่คืนประวัติช่วงต้นมาเป็นรอบที่ดูเหมือนสมบูรณ์ แต่คืนรอบว่างทั้งชุดและล้างเฉพาะเซฟรอบ ภาษาและธีมยังอยู่

`recovery()` ให้เหตุผลล่าสุด: NONE, MIGRATED, CORRUPT_SAVE, DATA_CHANGED หรือ UNSUPPORTED_VERSION เพื่อใช้เชื่อมข้อความแจ้งผู้เล่นในขั้น UI ต่อไป การแจ้งเหตุผลบนหน้าจอยังไม่ได้เชื่อมในงานชุดนี้

### รองรับผู้เรียกเดิม

ยังมี `open(day)` และ `save(round)` เพื่อรองรับจุดเรียกเดิม แต่ GameActivity ใช้ overload ที่ส่ง ranks เพื่อให้ตรวจโจทย์และอันดับได้ครบ

`language()` ใช้ค่า ""/"en"/"th" ส่วน `theme()` ใช้ "system"/"light"/"dark" การเพิ่ม API ธีมในขั้นนี้เป็นการเก็บค่าเท่านั้น การเปลี่ยนหน้าตาแอปต้องเชื่อมกับงาน UI ของคน 1

### จุดเชื่อมคำใบ้

GameActivity เรียก HintEngine เลือกคำ แล้วเรียก `round.hint(word, ranks)` เพื่อตัดสินตามกติกากลาง บันทึกเฉพาะเมื่อรับคำใบ้สำเร็จ ถ้าไม่มีคำหรือ GameRound ปฏิเสธ จะแสดง no_hint โดยไม่เซฟและไม่เพิ่มยอด

APK สร้างได้ที่ app/build/outputs/apk/debug/app-debug.apk การสร้าง APK สำเร็จยังไม่ใช่ผลทดลองบนมือถือ
